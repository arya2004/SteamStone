# Security

Never include a Steam API key, credential-store contents, authentication tokens, or private account data in a public issue or screenshot. If a key was exposed, revoke it through Steam and generate a replacement.

For a sensitive vulnerability, use the repository's **Security → Report a vulnerability** option if private reporting is enabled. If it is unavailable, open an issue requesting a private contact channel without exploit details or secrets. Do not publish sensitive details while arranging contact.

Include the affected version or commit, operating system, impact, and a minimal reproduction using synthetic data. Do not test achievement writes against another person's account. No response-time guarantee or bug bounty is offered.

SteamStone v1.0.0 is released. Only the latest published version is targeted for fixes. Downloads are not signed by a trusted Windows/macOS publisher; checksums establish file integrity, while GitHub attestations, when present, identify the build workflow. Neither guarantees that an application is free of vulnerabilities.
